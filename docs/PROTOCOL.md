# 通信协议与接口规范 V1.0

对应《设计说明文档》4.2 节软硬件接口设计、6.1/6.4 节工作流程。

## 1. 物理接口

| 接口 | 参数 |
| --- | --- |
| UART（RS232，DB9：2-RX / 3-TX / 5-GND） | 9600 bps，8 数据位，1 停止位，无校验 |
| CAN 2.0B（CAN_H / CAN_L / GND） | 500 kbps；系统地址 0x01，外部设备 0x02~0xFF |
| SPI（SD 卡扩展存储） | 18 MHz，模式 0，DMA ≥ 2MB/s |
| 电源 | DC 5V/1A，过压 ≥6V / 过流 ≥1.5A 保护 |

## 2. 帧格式（变长）

```
偏移  长度  字段
0     2    帧头 0xAA 0x55
2     1    设备地址 ADDR（入帧=源设备 0x02~0xFF；出帧=系统 0x01）
3     1    功能码 FC
4     2    数据长度 LEN（小端，单位字节，= DATA 实际长度）
6     LEN  参数载荷 DATA（小端字节序）
6+LEN 2    CRC16（XMODEM poly 0x1021，初值 0xFFFF；覆盖 ADDR~DATA 末字节）
8+LEN 2    帧尾 0x55 0xAA
```

| 功能码 | 方向 | 含义 |
| --- | --- | --- |
| 0x01 | 外部 → 系统 | 楼盖设计参数 |
| 0x02 | 外部 → 系统 | 肋梁设计参数（预留） |
| 0x81 | 系统 → 外部 | 计算结果输出帧 |
| 0x8F | 系统 → 外部 | NACK（载荷：源地址+原功能码+错误码） |
| 0x90 | 系统 → 外部 | ACK（载荷：源地址+原功能码） |

## 3. 参数载荷 FC 0x01（28 字节）

| 偏移 | 类型 | 字段 | 说明 |
| --- | --- | --- | --- |
| 0 | u8 | 混凝土强度等级 | 数值 20/25/.../80，查表映射 fc/ft |
| 1 | f32 | 跨度 X（mm） | 长边 |
| 5 | f32 | 宽度 Y（mm） | 短边 |
| 9 | f32 | 板厚（mm） | 80~600 |
| 13 | f32 | 配筋率 | 0.002~0.025 |
| 17 | u8 | 楼盖类型 | 0 单向板 / 1 双向板 |
| 18 | f32 | 恒荷载（kPa） | 0.5~25 |
| 22 | f32 | 活荷载（kPa） | 0~30 |
| 26 | u8 | 荷载持续时间分级 | 0:<1h 1:1h~1d 2:1d~1w 3:1w~1m 4:>1m |
| 27 | u8 | 保留 | 0 |

## 4. 结果载荷 FC 0x81（40 字节，帧总长 50 ≤ 128 字节）

| 偏移 | 类型 | 字段 | 定点格式 |
| --- | --- | --- | --- |
| 0 | u8 | 状态码 | 0x00 成功，其余同参数解析错误码 |
| 1 | u32 | 设计编号 | 唯一追溯标识 |
| 5 | u32 | 时间戳 | 系统毫秒节拍 |
| 9 | u16 | 跨度 X | mm |
| 11 | u16 | 宽度 Y | mm |
| 13 | u16 | 长期挠度 | 0.01 mm（×100） |
| 15 | u16 | 允许挠度 | 0.01 mm |
| 17 | u16 | 最大裂缝宽度 | 0.001 mm |
| 19 | u16 | 钢筋总重 | 0.1 kg |
| 21 | u8 | 校验标志 | bit0 挠度 / bit1 裂缝 / bit2 承载力 通过 |
| 22 | u8 | 板底 X 向钢筋 | 高 4 位直径编码，低 4 位间距/10 |
| 23 | u8 | 板底 Y 向钢筋 | 同上 |
| 24 | u8 | 支座 X 向顶筋 | 同上 |
| 25 | u8 | 支座 Y 向顶筋 | 同上 |
| 26 | u16 | 全截面配筋率 | 1e-5 |
| 28 | u16 | 安全储备 Mu/(K·M) | 0.01 |
| 30 | u8 | 实际迭代次数 | |
| 31 | u8 | 构造修正标志 | bit0 |
| 32 | u8 | 混凝土强度等级 | 数值 |
| 33 | u8 | 板类型 | 0/1 |
| 34 | u8 | 载荷版本号 | 0x01 |
| 35 | u8 | 保留 | |
| 36 | u32 | CRC32 | 覆盖偏移 0~35（IEEE 802.3） |

钢筋直径 4bit 编码：0=无，1~9 依次为 D8/D10/D12/D14/D16/D18/D20/D22/D25；
间距编码 = 间距 mm / 10（取整）。

## 5. 模块间接口（文档 4.2 节）

| 接口 | 形式 | 签名 |
| --- | --- | --- |
| 参数解析 ↔ 驱动 | 函数调用 | `Parse_Param(uint8_t *data, uint16_t len, DesignParam *param)` |
| 参数解析 → 结构计算 | 消息队列（长度 8） | `TaskQueue<DesignParam, 8>` |
| 结构计算 ↔ 配筋优化 | 共享内存 0x24000000 + 标志位 0xFF + CRC32 | `shared_mem_write/read`，优化结果定长 126B |
| 配筋优化 → 结果封装 | 函数调用 | `Package_Result(OptResult&, DesignParam&, status, uint8_t *out, uint16_t *out_len)` |
| 各模块 → 数据存储 | 消息队列（长度 16） | `Store_Data(StoreType type, const void *data, uint16_t len, uint32_t design_no)` |
| 结构计算回调 | 回调函数 | `Calc_Callback(CalcResult *result)`（任务内直接调用） |

## 6. 存储记录格式（NOR Flash，4KB 扇区/记录）

```
扇区头 28B：
  0   u32  魔数 "SDFR" (0x52464453)
  4   u32  设计编号
  8   u64  时间戳（ms）
  16  u8   StoreType（1 参数 / 2 计算结果 / 3 优化方案 / 4 输出帧）
  17  u16  数据长度
  19  u32  数据 CRC32
  23  u32  MD5(数据) 前 4 字节哈希索引
  27  u8   保留
偏移 28B 起：记录数据体
```

写入遵循"先擦后写、先写后改"的原子事务；同编号循环覆盖；空闲扇区
< 25% 触发垃圾回收；磨损均衡按扇区擦写次数最少优先分配。
